# Example applications

Applications are grouped by complexity, application and framework. Each implementation has its own README and dependencies.

- **Basic:** Counter — [HTML](basic/counter/html/README.md), [React](basic/counter/react/README.md), [GTK4](basic/counter/gtk4/README.md), [Iced](basic/counter/iced/README.md). Hello world — [COSMIC protocol simulation](basic/hello-world/cosmic/README.md) (does not launch COSMIC).
- **Medium:** [Pomodoro (HTML)](medium/pomodoro/html/README.md), [Notes (GTK4)](medium/notes/gtk4/README.md), [Tasks (HTML)](medium/tasks/html/README.md), [Unit calculator (HTML)](medium/unit-calculator/html/README.md).
- **Advanced:** Project workspace — [HTML](advanced/project-workspace/html/README.md), [React](advanced/project-workspace/react/README.md), [Iced](advanced/project-workspace/iced/README.md), [COSMIC](advanced/project-workspace/cosmic/README.md).

Protocol fixture tests: `cargo test -p rupicola-protocol --test hello_worlds`.
